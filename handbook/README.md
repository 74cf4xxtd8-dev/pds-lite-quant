## 근거 표기

모든 문서는 각 서술이 무엇으로 확인됐는지 다음 표시로 구분합니다. 표시가 없는 문단은 바로 위 표시를 따릅니다.

| 표시 | 뜻 |
|---|---|
| **[코드]** | 기준 커밋의 소스코드·워크플로를 읽어 확인 |
| **[데이터]** | 기준 커밋의 `docs/data` 파일, Actions 실행 기록, 테스트 실행 결과로 확인 |
| **[원작자]** | 원작자(SlackQuant) 공개 저장소·워크북·문서에 근거. PDS-Lite가 만든 것이 아님 |
| **[추정]** | 공개 결과나 과거 사례로 추정. 보장되지 않음 |
| **[미확인]** | 이 문서 작성 시점에 확인하지 못함. 운영 전에 직접 확인 필요 |

## 공통 용어

| 용어 | 뜻 |
|---|---|
| 원작자 | SlackQuant(GitHub `slackquant80`). PDS 전략과 ADAA·F2R 규칙, 공개 워크북·F2R JSON을 만든 쪽. PDS-Lite는 이를 공개 자료로 재구성한 개인용 시스템이다 |
| PDS-Lite | 이 저장소. 목표 비중을 계산·확정·표시만 한다. **주문을 내지 않는다** |
| 신호월(signal month) | 비중을 계산하는 기준 달. 그 달 마지막 미국 거래일 종가까지의 가격을 쓴다 |
| 보유월(holding month) | 신호월 다음 달. 신호월 목표를 들고 있는 달. "1~10일"과 "10일 마감"은 보유월 날짜(UTC)다 |
| Core | 0.90 × ADAA + 0.10 × F2R. 원작자 공개 Core와 같아야 한다 |
| ADAA | 5개 규칙(HAA·BAA·ADM·FAA·LAA)의 가중 혼합 |
| F2R | 원작자의 Forecast-to-Rank 모델이 고른 Top-4 ETF(각 25%) |
| Adaptive | RB × Core + (1 − RB) × BIL |
| RB(Risk Budget) | Core에 싣는 비율. **RB = 100%는 방어 모드가 아니라 Core 100%(NORMAL)이다.** RB < 100%일 때만 DEFENSIVE이고 나머지를 BIL(초단기 국채)에 둔다 |
| Official(공식 목표) | 잠금된 가장 최근 신호월의 목표. **실제 리밸런싱은 이것만 기준으로 한다** |
| 잠금(Lock) | 신호월 결정을 `docs/data/official_history.json`에 기록하는 것. 한 번 잠긴 달은 다시 계산하지 않는다 |
| Preview | 아직 잠기지 않은 달의 계산값(월중 추정, 또는 잠금 대기·보류 중인 달). **공식 목표가 아니며 매매에 쓰지 않는다** |
| 잠금 대기(WAIT / PENDING) | 신호월은 끝났지만 공식 자료(원작자 F2R 공식 Top-4, 원작자 Core)가 아직 없거나 맞지 않아 잠그지 못한 상태. 직전 Official 유지 |
| 잠금 보류(BLOCKED, action HALTED) | 보유월 10일 22:00 UTC 이후에도 공식 자료가 갖춰지지 않은 상태. 자동 잠금 없음, 보유 유지, 수동 해제로만 잠금 |
| 운영자 중지(PDS_HALT) | 저장소 변수 `PDS_HALT`로 거는 중지. 그 동안의 실행은 읽기 전용이다 |
| 수동 해제(manual release) | 보류된 달을 사람이 승인해 잠그는 예외 절차 |
| 빈 달(gap, `unlocked_gaps`) | 보류된 채 다음 달이 먼저 잠겨 영원히 잠기지 않게 된 달 |
| 참고 원장 | `reference_adaptive.json`. 원작자가 공개한 Adaptive 값을 처음 본 시각·수정 이력과 함께 쌓는 기록. 잠금을 바꾸지 않는다 |
| 감사 기록 | `official_events.json`. 대기·불일치·보류·잠금·수동 해제 사건 기록(추가만 가능) |
| fail-closed | 검사 하나라도 실패하면 아무 파일도 쓰지 않고 직전 공식 목표를 유지하는 방식 |
| 봇 커밋 | update-portfolio 워크플로가 `github-actions[bot]` 이름으로 `docs/data`에 올리는 커밋 |
| LIVE / RECONSTRUCTED | 잠금 기록의 분류. LIVE = 예약 실행이 신호 컷오프 14일 이내에 잠근 실시간 기록. 그 외(백필·수동 해제·늦은 잠금)는 RECONSTRUCTED |

시각: 코드와 데이터의 시각은 모두 UTC입니다. 한국 시간(KST)은 UTC + 9시간입니다. 예약 실행 22:40 UTC는 다음 날 07:40 KST입니다.
